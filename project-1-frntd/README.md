# GCTC Study Hub

AI-powered study companion for GCTC students — ask questions, explore past papers, and master your subjects.

## Tech Stack

React 19 · Vite 7 · Framer Motion · Tailwind CSS v4 · React Router · Lucide React

## Getting Started

```bash
npm install
npm run dev
```
